# Onyx Mobile 개인정보 처리 안내

시행일: 2026-11-18

Onyx Mobile은 로그인이나 서버 없이 동작하는 Pocket AMP 에디터입니다.
앱에는 광고, 분석 SDK, 사용자 추적 기능이 없습니다.

Bluetooth는 주변 앰프의 이름·식별자·신호 세기를 확인하고 연결하여 설정을
읽고 쓰는 데 사용합니다. 마지막으로 연결한 앰프의 이름과 Bluetooth
식별자는 기기 내부에 저장합니다. 위치 좌표를 수집하거나 저장하지 않습니다.
Android 11 이하에서 요청하는 위치 권한과 위치 서비스는 OS의 BLE 검색
요구사항 때문에 사용합니다. Android 12 이상은 근처 기기 권한을 사용합니다.
iOS는 Bluetooth 권한을 사용합니다.

사용자가 선택한 프리셋, NAM, IR 파일은 기기에서 처리합니다. 가져온 파일과
최근 작업 기록은 실행 중 메모리에 유지합니다. 파일 저장과 공유는 사용자가
명시적으로 선택할 때만 OS의 기능으로 수행합니다. 공유할 백업의 임시 파일은
앱의 임시 저장소에 생성됩니다. 임시 저장소는 OS의 정리 또는 앱 삭제로
제거할 수 있습니다. 공유 대상 앱과 클라우드 파일 제공자의 데이터 처리는
각 서비스의 개인정보 처리방침을 따릅니다.

프로젝트 링크는 사용자가 선택하면 외부 브라우저로 열립니다. 앱은 편집
데이터를 개발자에게 전송하지 않습니다. 앱 삭제로 내부에 보관된 연결 기록과
임시 파일을 제거할 수 있습니다. 사용자가 별도로 저장한 백업은 저장 위치에서
직접 삭제해야 합니다.

배포자는 스토어에 이 문서를 게시할 때 자신의 문의처와 배포 앱의 실제
개인정보 처리 내용을 추가해 주세요.
